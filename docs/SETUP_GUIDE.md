# Chem Paper Daily セットアップ手順書

毎朝、化学の新しい論文を1本選んで、英語の紹介文（日本語の要点と重要単語つき）を Slack に届けるアプリです。
ブラウザで過去の紹介を読み返したり、読んだ論文の PDF を「本棚」で管理したりできます。

この手順書は、コマンド（黒い画面に文字を打つ操作）に慣れていない人向けに書いています。
基本はダブルクリックと、メモ帳での書き換えだけです。全部で 30〜60 分くらいかかります。

> **用意するもの**
> - Windows 10 または 11 の PC（インターネットにつながっていること）
> - 契約中の Claude のアカウント（Pro などの有料プラン）
> - メールアドレス（Slack の登録と、論文データベースへの連絡先に使います）

---

## もくじ

1. アプリをダウンロードして展開する
2. setup.bat を実行する
3. Claude Code をインストールしてログインする
4. Slack を準備して、Webhook URL を .env に貼り付ける
5. config.toml に自分のメールアドレスを書く
6. 初めての動作確認
7. 毎日の使い方
8. 困ったときは
9. 付録: API 方式（従量課金）に切り替える

## 1. アプリをダウンロードして展開する

1. ブラウザで GitHub のページ（https://github.com/kenbridge1615-collab/chem-paper-daily ）を開きます。
2. 緑色の **「Code」** ボタンをクリックし、いちばん下の **「Download ZIP」** をクリックします。
3. ダウンロードした ZIP ファイル（`chem-paper-daily-....zip`）を、エクスプローラーで右クリックして **「プロパティ」** を開きます。
   下のほうに **「許可する」**（セキュリティ: このファイルは他のコンピューターから取得したものです…）というチェックがあれば、チェックを入れて **「OK」** を押します。
   （これをしておくと、あとで出る警告が減ります。チェックが無ければそのままで大丈夫です。）
4. ZIP を右クリックして **「すべて展開」** を選び、展開先を決めます。
   おすすめは **ドキュメント** フォルダの中です（例: `C:\Users\あなたの名前\Documents\chem-paper-daily`）。
   - デスクトップや OneDrive の中は、同期の影響でうまく動かないことがあるので避けてください。
   - 展開したあとは、フォルダを別の場所へ移動しないでください（毎朝の自動実行がそのフォルダを指しています）。移動した場合は 2 番をやり直します。
5. 展開したフォルダを開き、`setup.bat`、`start.bat`、`run_daily.bat`、`config.toml` などが並んでいることを確認します。
   （フォルダの中にもう1つ同じ名前のフォルダがある場合は、その中が本体です。）

> **ファイルの拡張子を表示しておくと便利です**: エクスプローラー上部の **「表示」** →（Windows 11 は **「表示」→「表示」**）→ **「ファイル名拡張子」** にチェック。`.env` や `.bat` が見分けやすくなります。

---

## 2. setup.bat を実行する

1. フォルダの中の **`setup.bat`** をダブルクリックします。
2. 青い画面で **「WindowsによってPCが保護されました」** と出た場合は、**「詳細情報」** をクリックしてから **「実行」** を押します。
   （インターネットから取ってきたファイルなので出る警告です。）
3. 黒い画面が開き、次の 5 つが順番に進みます。初回は数分かかります。
   1. uv（Python を管理するツール）のインストール
   2. Python と必要なライブラリのインストール
   3. 設定ファイル `.env` の作成
   4. Claude Code があるかの確認
   5. 毎朝 7:00 に動くよう、Windows の「タスク スケジューラ」に登録
4. 最後に緑色で **「セットアップが終わりました！」** と出れば成功です。何かキーを押すと画面が閉じます。
   - 4 番で「Claude Code が見つかりません」と黄色で出るのは、この時点では普通です。次の 3 番で入れます。
   - 赤い「エラー」が出たら、8 番「困ったときは」を見てください。

**タスクの登録内容**（参考）: 毎日 7:00 に `run_daily.bat` を実行します。
「ログオンしているときだけ実行」「時刻に PC が起動していなかったら、次に起動したときにすぐ実行」という設定です。
同じ日に2回 Slack に届くことはありません。

## 3. Claude Code をインストールしてログインする

紹介文は、あなたが契約している Claude のプランを **Claude Code** というツール経由で使って書きます（追加料金なし）。

> **インストール方法は変わることがあります。** 必ず公式ページの最新の手順を確認して、その通りに進めてください。
> - 公式クイックスタート（日本語）: https://code.claude.com/docs/ja/quickstart
> - 黒い画面（ターミナル）を使ったことがない人向けの公式ガイド: https://code.claude.com/docs/ja/terminal-guide
>
> デスクトップアプリ版ではなく、**ターミナルで `claude` と打って使う版（CLI）** が必要です。

だいたいの流れ（細かい部分は公式ページに合わせてください）:

1. スタートメニューで **「PowerShell」** と検索し、**「Windows PowerShell」** を開きます（`PS C:\Users\...>` と表示される青か黒の画面）。
2. 公式ページの **Windows（PowerShell）用** のインストールコマンドをコピーし、PowerShell の画面で右クリックして貼り付け、Enter を押します。
   （執筆時点では `irm https://claude.ai/install.ps1 | iex` という形でした。必ず公式ページのものを使ってください。）
   - 公式ページに「Git for Windows が必要」などと書かれていたら、その案内に従って先に入れてください。
3. インストールが終わったら、**PowerShell の画面をいったん閉じて、新しく開き直します。**
4. `claude --version` と入力して Enter。バージョン番号（例: `2.x.x`）が出ればインストール成功です。
5. 続けて `claude` と入力して Enter。初回はログインの案内が出ます。
   **「Claude アカウント（サブスクリプション）でログイン」** の方を選び、開いたブラウザで、契約中のアカウントでログインして許可します。
   - 「API キー」「Anthropic Console」でのログインを選ぶと従量課金になります。ここではサブスクリプションの方を選んでください。
6. ログインできたら、`/exit` と入力して Enter（または Ctrl キーを押しながら C を 2 回）で終了し、PowerShell を閉じます。
7. もう一度 **`setup.bat` をダブルクリック** します。4 番で「Claude Code が見つかりました」と緑で出れば OK です。

> **安全について**: このアプリは Claude Code を呼ぶとき、ファイル操作やコマンド実行などのツールを全部オフにし、空の一時フォルダで動かしています。論文の要旨に変な指示が紛れ込んでいても、Claude があなたの PC を操作することはありません。

## 4. Slack を準備して、Webhook URL を .env に貼り付ける

毎朝の紹介は Slack に届きます。自分専用のワークスペース（自分だけの Slack の部屋）を作るのがおすすめです。

### 4-1. 自分用のワークスペースを作る（すでにあれば飛ばして OK）

1. ブラウザで https://slack.com/get-started#/createnew を開きます。
2. メールアドレスを入れ、届いた確認コードを入力します。
3. **「ワークスペースを作成する」** を選び、名前（例: `chem-daily`）を決めます。
4. メンバーの招待などは **「スキップ」** して構いません。
5. 紹介を受け取るチャンネルを作ります（例: `#paper-daily`）。最初からある `#general` などでも大丈夫です。
6. スマホでも読みたい場合は、Slack アプリを入れて同じワークスペースにログインしておきます。

### 4-2. Incoming Webhook（投稿用の URL）を作る

1. ブラウザで https://api.slack.com/apps を開き、作ったワークスペースのアカウントでログインします。
2. **「Create New App」** → **「From scratch」** を選びます。
3. App Name に `Chem Paper Daily`、ワークスペースに 4-1 で作ったものを選び、**「Create App」**。
4. 左のメニューの **「Incoming Webhooks」** を開き、右上のスイッチを **On** にします。
5. 下にスクロールして **「Add New Webhook to Workspace」**（または「Add New Webhook」）をクリックします。
6. 投稿先のチャンネル（例: `#paper-daily`）を選んで **「許可する」**。
7. 表に `https://hooks.slack.com/services/...` で始まる URL が出ます。**「Copy」** を押してコピーします。

> この URL を知っている人は誰でもあなたの Slack に投稿できます。人に見せたり、SNS やチャットに貼ったりしないでください。
> アプリはこの URL を画面やログに表示しません。

画面の表示や名前は Slack 側の変更で少し違うことがあります。迷ったら Slack の公式ヘルプで「Incoming Webhook」を検索してください。

### 4-3. .env に貼り付ける

1. アプリのフォルダにある **`.env`** を右クリック → **「プログラムから開く」** → **「メモ帳」** を選びます。
   （`.env` が見当たらないときは 2 番の setup.bat がまだ終わっていません。）
2. `SLACK_WEBHOOK_URL=` の行の `=` のすぐ後ろに、コピーした URL を貼り付けます。前後に空白を入れないでください。

   ```
   SLACK_WEBHOOK_URL=https://hooks.slack.com/services/T0000/B0000/xxxxxxxx
   ```
3. **Ctrl + S** で保存して、メモ帳を閉じます。
   `ANTHROPIC_API_KEY=` の行は空のままで大丈夫です（9 番の API 方式に切り替えるときだけ使います）。

## 5. config.toml に自分のメールアドレスを書く

論文データベース（Crossref と Unpaywall）は、連絡先メールアドレスを付けて問い合わせるのがマナーで、付けると安定して使えます。

1. **`config.toml`** を右クリック → **「プログラムから開く」** → **「メモ帳」**。
2. 上のほうにある次の行を探します。

   ```
   contact_email = "you@example.com"
   ```
3. `you@example.com` の部分を自分のメールアドレスに書き換えます。**`"`（ダブルクォーテーション）は消さないでください。**

   ```
   contact_email = "taro.tohoku@example.ac.jp"
   ```
4. Ctrl + S で保存します。

**ほかに変えられること**（変えなくても動きます）:

| 項目 | 場所 | 初期値 |
|---|---|---|
| 1日に紹介する上限（「もう1本」も含む） | `[limits]` の `max_intros_per_day` | 3 |
| ジャンルの割合 | `[genre]` の `electrochem` / `other` | 0.4 / 0.6 |
| 雑誌のリスト | `[[journals]]` | JACS、Anal. Chem. など 16 誌 |
| キーワードと重み | `[scoring.keywords]` | ionophore、pH sensor など |
| 東北大の学外アクセス用リンクの形式 | `[fulltext]` の `proxy_url_template` | 図書館のページで確認して書き換えてください |

通知時刻（`notify_time`）を変えたときは、保存したあと **setup.bat をもう一度実行** すると、タスクの時刻も変わります。

## 6. 初めての動作確認

### 6-1. 毎朝のジョブを手動で 1 回動かす

1. **`run_daily.bat`** をダブルクリックします。
2. 「Running the daily job...」と出て、数分待ちます（論文を集めて、Claude が紹介文を書いています）。
3. 終わると、ログの最後の部分が表示されます。
   - `Finished OK.` と出て、**Slack に今日の論文が届いていれば成功** です！
   - 何かキーを押すと画面が閉じます。
4. うまくいかなかったときは、表示されたログを見て 8 番「困ったときは」へ。
   ログの全文は `data\logs\run_daily.log` と `data\logs\daily_job.log`（メモ帳で開けます）にあります。

> 毎朝のジョブは **1日1回だけ** 動きます。同じ日に run_daily.bat をもう一度実行すると、ログに `already exists; skipping` と出て何もしません。これは二重投稿を防ぐための正常な動きです。
> 同じ日にもう1本読みたいときは、Webアプリの「もう1本」ボタンを使います。

### 6-2. Webアプリを開く

1. **`start.bat`** をダブルクリックします。
2. 黒い画面が開き、少しするとブラウザで **http://127.0.0.1:8765** が開きます。
3. 「今日の1本」に、6-1 で作られた紹介が表示されれば成功です。
4. **黒い画面はアプリ本体です。閉じるとアプリが止まります。** 使い終わったら閉じて構いません。
   （閉じても、毎朝の Slack 通知は届きます。）

このアプリはあなたの PC の中だけで動いていて、ほかの PC やスマホからは開けません。

## 7. 毎日の使い方

- **毎朝**: PC にログオンしていれば、7:00 ごろ Slack に今日の1本が届きます。PC を起動していなかった日は、次に起動してログオンしたときに届きます。
- **じっくり読む**: `start.bat` でアプリを開きます（Slack の「Read on web」ボタンからも、アプリが起動していれば開けます）。

Webアプリの画面:

| 画面 | できること |
|---|---|
| 今日の1本 | 紹介文（Background / What they did / Key results / Why it matters）、日本語の要点、重要単語、考えるための問い。👍 / 👎、本棚に追加、「もう1本」 |
| これまでの紹介 | 過去の紹介の一覧。キーワード検索、ジャンル・雑誌で絞り込み |
| 本棚 | 読みたい / 読んでる / 読んだ の管理、メモ、PDF の登録と表示。DOI を入れて紹介以外の論文も追加できます |
| 設定 | 今の設定、今月使ったトークン数、毎朝のジョブの結果 |

- **「要旨ベースの紹介」**: 紹介文は論文の要旨（Abstract）だけをもとに書いています。細かい数値や結論は、必ず全文で確かめてください。
- **全文を読む**: 「DOI」は出版社のページ、「東北大の学外アクセス経由」は大学の契約で読むためのリンク、「オープンアクセス版 PDF」は無料で読める版です。
  学内ネットワークにいるときは DOI のリンクのままで読めることが多いです。
- **PDF の保存**: アプリは論文の PDF を自動でダウンロードしません。自分で正規に読んだ PDF をパソコンに保存し、論文のページの「PDF を登録」から登録します。登録した PDF は `data\pdfs` フォルダに入ります。
- **👍 / 👎**: 押した評価は、次の日からの論文選びに反映されます（同じ雑誌や同じキーワードの論文が選ばれやすく / 選ばれにくくなります）。

**バックアップ**: 大事なデータは全部 `data` フォルダ（`app.db` と `pdfs`）にあります。ときどき `data` フォルダごと USB メモリやクラウドにコピーしておくと安心です。

## 8. 困ったときは

| 症状 | 原因と対処 |
|---|---|
| setup.bat で「uv のインストールに失敗」 | インターネットにつながっているか確認し、もう一度 setup.bat を実行します。大学の Wi-Fi で失敗する場合は、自宅のネットワークで試してください。 |
| setup.bat で「ライブラリのインストール（uv sync）に失敗」 | 同上。ウイルス対策ソフトが止めている場合もあります。PC を再起動してから再実行してみてください。 |
| setup.bat で「タスクスケジューラへの登録に失敗」 | 会社や大学の管理 PC では登録が禁止されていることがあります。個人の PC で試すか、毎朝 run_daily.bat を手動でダブルクリックしてください。 |
| 「Claude Code が見つかりません」 | 3 番をやり直します。インストール後は PowerShell を開き直してから `claude --version` を確認してください。それでもダメなら PC を再起動して setup.bat を再実行します。 |
| Slack に「Claude Code is not logged in」と届く | PowerShell で `claude` を実行し、サブスクリプションのアカウントでログインし直します。 |
| Slack に「usage limit」と届く | Claude の利用枠の上限に達しています。時間をおけば回復します。翌朝のジョブで普通に届きます。 |
| Slack に何も届かない | `.env` の `SLACK_WEBHOOK_URL=` の後ろに URL が正しく貼られているか（空白・改行が混ざっていないか）確認します。Webアプリの「設定」で「Slack Webhook URL: 設定済み」になっているかも見てください。 |
| run_daily.bat で `already exists; skipping` | 今日の分はもう実行済みです（正常）。翌日まで待つか、Webアプリの「もう1本」を使ってください。 |
| 朝 7:00 に届かない | PC がスリープ / シャットダウンしていると、起動してログオンしたときに届きます。スタートメニューで「タスク スケジューラ」を開き、「タスク スケジューラ ライブラリ」に **ChemPaperDaily** があるか確認してください。無ければ setup.bat を再実行します。 |
| 朝 7:00 に黒い画面が一瞬開く | 毎朝のジョブが動いている印です。閉じずにそのままにしておけば、終わると自動で消えます。 |
| start.bat でブラウザが開かない | ブラウザで http://127.0.0.1:8765 を直接開いてください。黒い画面にエラーが出ていたら、その内容を控えておきます。 |
| 「東北大の学外アクセス経由」のリンクで開けない | `config.toml` の `proxy_url_template` が東北大附属図書館の今の方式と合っていない可能性があります。図書館のウェブサイトで「学外からのアクセス」の方法を確認し、`{doi}` の部分に DOI が入る形で書き換えてください。 |
| PDF が登録できない | `.pdf` のファイルだけ登録できます。中身が PDF でないファイル（名前だけ .pdf に変えたものなど）や 100 MB を超えるファイルは登録できません。 |
| フォルダを移動したら毎朝届かなくなった | 新しい場所で setup.bat をもう一度実行してください。 |

ログの場所: `data\logs\run_daily.log`（毎朝のジョブの全出力）、`data\logs\daily_job.log`（アプリの記録）。
ログに Slack の URL や API キーは書かれません（自動で伏せ字になります）。人に相談するときはログを見せても大丈夫です。

## 9. 付録: API 方式（従量課金）に切り替える

将来、Claude Code 経由の利用（`claude -p`）の扱いが変わって使えなくなったり追加料金がかかるようになったりした場合は、
Anthropic の API（使った分だけ払う方式）に切り替えられます。**お金がかかる** ので、必ず月の上限を設定してください。

1. ブラウザで https://console.anthropic.com を開き、アカウントを作ってログインします（Claude のチャット用アカウントとは別の支払い設定になります）。
2. **支払い方法（Billing）** を登録し、クレジットを購入します。
3. **月の利用上限（Limits / Spend limit）** を設定します。例えば月 500 円〜1,000 円程度にしておけば、使いすぎることはありません。
   （このアプリは 1 日 1〜3 回しか呼ばないので、使う量はわずかです。）
4. **API Keys** の画面で **「Create Key」** を押し、`sk-ant-` で始まるキーをコピーします。キーは一度しか表示されないので、すぐ次へ進みます。
5. `.env` をメモ帳で開き、`ANTHROPIC_API_KEY=` の後ろに貼り付けて保存します。

   ```
   ANTHROPIC_API_KEY=sk-ant-xxxxxxxx
   ```
6. `config.toml` をメモ帳で開き、`[llm]` のところを次のように変えて保存します。

   ```
   backend = "api"
   ```
7. API 方式には追加のライブラリが必要です。**setup.bat をもう一度ダブルクリック** すると、`backend = "api"` を読み取って自動で入れます。
8. run_daily.bat で動作確認します（6-1 と同じ）。Webアプリの「設定」で「生成方式: Claude API（従量課金）」になっていれば切り替え完了です。

Console の画面の名前は変わることがあります。迷ったら Anthropic の公式ドキュメントを確認してください。
元に戻すときは、`backend = "claude_code"` に戻すだけです。
